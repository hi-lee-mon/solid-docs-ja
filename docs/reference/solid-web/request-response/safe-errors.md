`error` をクライアントへそのままシリアライズして安全なものとしてマークし、本番環境のエラーサニタイズの対象から外します（`handleServerFunctionRequest` を参照）。メッセージやプロパティが意図的にクライアント向けコンテンツであるエラーに使用します。`throw markSafeError(new Error(...))` と書きやすいよう、同じ値を返します。

## インポート

```ts
import { markSafeError, isSafeError } from "@solidjs/web";
```


#### `error`

- **型:** `E`
