現在のリクエストが属するトレース — 受信した W3C `traceparent` があればそれを継続し、なければランタイムが生成します。observe/dev ビルドでは、インストールされたプロバイダーの回答（`OBSERVE.server.trace`）とマージされます。リクエスト内でのすべての読み取りでは同じオブジェクトが返されます（サーバー関数の直接呼び出しを含む）。リクエストスコープ外のレンダーでは、そのレンダー自身のトレースです。どちらにも該当しない場合と、クライアントでは `undefined` です。サーバー関数から下流へ転送するには `getTraceContext()?.entries.traceparent` を使います。

## インポート

```ts
import { getTraceContext } from "@solidjs/web";
```

## 型シグネチャ

```ts
function getTraceContext(): TraceContext | undefined;
```

## 例

```ts
await fetch(url, { headers: { ...getTraceContext()?.entries } });
```

## 関連する型

### `TraceContext`

現在のリクエストが属するトレース — 受信した W3C `traceparent` があればそれを継続し、なければランタイムが生成します。`getTraceContext()` で読み取ります。

```ts
interface TraceContext {
  traceId: string;
  spanId: string;
  parentId?: string;
  sampled?: boolean;
  state?: string;
  baggage?: string;
  entries: Record<string, string>;
};
```

#### `traceId`

- **型:** `string`

32文字の小文字 hex — トレース全体の ID。

#### `spanId`

- **型:** `string`

16文字の小文字 hex — このリクエストのスパン。プロバイダーが提供しない限りランタイムが生成します。

#### `parentId`

- **型:** `string`

リクエストがトレースを継続した場合の、受信した親スパン。

#### `sampled`

- **型:** `boolean`

受信した `traceparent` の sampled フラグ（ビット 0）。ランタイムが生成した場合は `undefined`。

#### `state`

- **型:** `string`

受信した `tracestate` ヘッダー（そのまま）。

#### `baggage`

- **型:** `string`

受信した `baggage` ヘッダー（そのまま）。

#### `entries`

- **型:** `Record<string, string>`

最初のレスポンスでブラウザに渡される名前付きエントリー — `Server-Timing` エントリー（`<name>;desc="<value>"`）として、また HTML ドキュメントの場合はシェル内の `<meta name="<name>" content="<value>">` として出力されます。ランタイムが `traceparent` を設定し、プロバイダーがベンダー固有のペア（`sentry-trace`、`baggage`）を追加します。アプリケーションコードが下流へ転送するのもこれです: `fetch(url, { headers: { traceparent: entries.traceparent } })`。

### `TraceProvider`

オブザーバーが返す、リクエストが属するトレースの回答で、ランタイムのデフォルトの導出結果にマージされます。返されたフィールドは導出されたものを置き換え（APM のアクティブスパンからの `traceId`/`spanId` など）、その `entries` はランタイムのものに名前でマージされます。リクエストごとに1回（リクエストスコープ外のレンダーではレンダーごとに1回 — その場合 `request` は `undefined`）、シェルのフラッシュ時または最初の `getTraceContext()` のどちらか早い方で呼び出されます。`undefined` を返すと導出結果がそのまま使われます。

```ts
type TraceProvider = (request: Request | undefined) => Partial<TraceContext> | undefined;
```

### `TraceSlot`

このパッケージが名付けるプロバイダースロットの型 — `solid-js` の `ServerTrace` で、上記のように補完されます。

```ts
type TraceSlot = ServerTrace;
```
