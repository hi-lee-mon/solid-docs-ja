`Cookie` リクエストヘッダーを 名前 → 値 のマップにパースします。
名前と値は `decodeURIComponent` でデコードされます（デコードが
例外を投げた場合は生のテキストにフォールバックします — 他の
プロデューサーが設定したクッキーは必ずしもパーセントエンコード
されていません）。引用符で囲まれた値は RFC 6265 文法に従って
その内容を保持します。`null` または空の入力は空のマップに
パースされます。

プラットフォームギャップの読み取り側です — 推奨されるリクエスト
クッキーの読み取りは
`parseCookieHeader(event.request.headers.get("cookie"))` です。

## 関連型

### `CookieOptions`

```ts
interface CookieOptions {
  path?: string;
  domain?: string;
  maxAge?: number;
  expires?: Date;
  httpOnly?: boolean;
  secure?: boolean;
  sameSite?: "lax" | "strict" | "none" | "Lax" | "Strict" | "None";
  partitioned?: boolean;
};
```

#### `path`

- **型:** `string`

クッキーの `Path` 属性。デフォルトは `/`。

#### `domain`

- **型:** `string`

クッキーの `Domain` 属性。指定された場合のみ出力されます。

#### `maxAge`

- **型:** `number`

クッキーの `Max-Age` 属性（秒単位、整数に切り捨て）。

#### `expires`

- **型:** `Date`

クッキーの `Expires` 属性。

#### `httpOnly`

- **型:** `boolean`

`HttpOnly` 属性を出力します。

#### `secure`

- **型:** `boolean`

`Secure` 属性を出力します。

#### `sameSite`

- **型:** `"lax" | "strict" | "none" | "Lax" | "Strict" | "None"`

クッキーの `SameSite` 属性（大文字小文字は問いません）。

#### `partitioned`

- **型:** `boolean`

`Partitioned` 属性（CHIPS）を出力します。設定されたトップレベル
サイトに紐づくサードパーティクッキー — ブラウザが他の
サードパーティクッキーを廃止し終えても動作し続ける唯一の
サードパーティクッキーです。`secure` が必要です。
