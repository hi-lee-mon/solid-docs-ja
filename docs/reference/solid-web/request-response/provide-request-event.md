`AsyncLocalStorage` を基盤とするサーバーのリクエストイベントスコープ内でコールバックを実行します。

## インポート

```ts
import { provideRequestEvent } from "@solidjs/web/storage";
```

## 型シグネチャ

```ts
function provideRequestEvent<T extends RequestEvent, U>(init: T, cb: () => U): U;
```

## パラメータ

### `init`

- **型:** `T`

このリクエストのイベント — フレームワークはよりリッチなイベントの形を渡します

### `cb`

- **型:** `() => U`

同期的に実行され、その戻り値がそのまま返されます

## 例

```ts
import { provideRequestEvent } from "@solidjs/web/storage";

async function handler(request: Request) {
  return provideRequestEvent({ request, locals: {} }, () =>
    renderToStream(() => <App />)
  );
}
```
