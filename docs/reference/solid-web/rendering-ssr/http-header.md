SSR 中に、現在のリアクティブスコープの存続期間にわたって HTTP
レスポンスヘッダーを宣言します（`append` を使うと既存のヘッダーに追加します）。
コンポーネントまたはリアクティブスコープの本体でそのまま呼び出します。
クライアントビルドでは何もしません — レスポンスヘッドはとうに送信済みです。

命名に関する補足 — これはスコープに紐づく*宣言*であり、ミューテーションでは
ありません。「このリアクティブスコープが生きている間、レスポンスはこの
ヘッダーを持つ」という意味です。Solid は `set*` 動詞をイベント時の
ミューテーション用に予約しています。`createSignal`/`onCleanup` と同様に、
これはスコープ本体で呼び出され、スコープの破棄時に宣言が取り消されます。

撤回のセマンティクス（サーバー）: ヘッダーの以前の値は書き込み時に
スナップショットされ、所有スコープが破棄されると復元されます（以前の値が
なければ削除されます）。エラーになったり回復したりするバウンダリは、
その書き込みを撤回します。レスポンスヘッドが `committed`
（ヘッドが確定・送信済み — パイプされた `renderToStream` の
シェルフラッシュ、await されたものまたは `renderToString` の完了）
になると、書き込みと撤回は何もしなくなります。

## インポート

```ts
import { httpHeader } from "@solidjs/web";
```

## 型シグネチャ

```ts
function httpHeader(name: string, value: string, options?: { append?: boolean }): void;
```

## パラメータ

### `name`

- **型:** `string`

ヘッダー名。

### `value`

- **型:** `string`

ヘッダー値。

### `options`

- **型:** `{ append?: boolean }`
- オプション

`append: true` で、ヘッダーを置き換える代わりに値を追加します。

## 例

### ページにキャッシュポリシーを設定する

```tsx
function ProductPage() {
	httpHeader("Cache-Control", "public, max-age=60");
	return <Product />;
}
```

### ヘッダーを追加する

```ts
httpHeader("Link", "</fonts/inter.woff2>; rel=preload; as=font", { append: true });
```

## 注意点

- SSR 中にコンポーネントまたはリアクティブスコープの本体で呼び出してください。ブラウザでは何もしません。
- レスポンスヘッドが確定した後（ストリームのシェルフラッシュ後）の書き込みは無視されます。
