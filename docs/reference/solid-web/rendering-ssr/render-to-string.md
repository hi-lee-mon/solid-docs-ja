コンポーネントツリーを同期的に HTML 文字列にレンダーします。
`<Loading>` バウンダリ内の非同期読み取りは `fallback` コンテンツを
出力します。グラフ全体を解決するには代わりに `renderToStream` を
await してください。

返された HTML はクライアントで `hydrate()` と組み合わせてください。

## インポート

```ts
import { renderToString } from "@solidjs/web";
```

## 型シグネチャ

```ts
function renderToString<T>(
  fn: () => T,
  options?: {
    nonce?: CSPNonce;
    renderId?: string;
    noScripts?: boolean;
    plugins?: any[];
    manifest?: AssetManifest | AssetResolver | AssetResolverFn;
    /** This render's server error hook, ahead of `configureServerErrors`' (see the server entry). */
    onError?: ServerErrorHook;
    /**
     * Embedded-render contract for hosts that own the document. When the
     * render output contains no `</head>`, everything head-bound (resolved
     * `useHead` winners, eager resources, tracked asset links, inline
     * styles) is delivered here as one HTML string — prelude (charset/base)
     * first — for the host to splice into its own `<head>` template, instead
     * of being dropped. Called synchronously before `renderToString`
     * returns; not called when the output has a `</head>` (splicing is
     * automatic then).
     */
    onHead?: (head: string) => void;
  }
): string;
```

## パラメータ

### `fn`

- **型:** `() => T`

ルート JSX を返す関数。

### `options`

- **型:** `{ nonce?: CSPNonce; renderId?: string; noScripts?: boolean; plugins?: any[]; manifest?: AssetManifest | AssetResolver | AssetResolverFn; onError?: ServerErrorHook; onHead?: (head: string) => void; }`
- オプション

CSP 用の `nonce`、ハイドレーション ID プレフィックス用の `renderId`、ハイドレーションスクリプトを省略する `noScripts`、アセット解決用の `manifest`、`onError`、そしてドキュメントを所有するホスト用の `onHead`。

## 戻り値

レンダーされた HTML 文字列。

## 例

```tsx
import { renderToString } from "@solidjs/web";

const html = renderToString(() => <App />);
res.send(`<!doctype html><html><body><div id="root">${html}</div></body></html>`);
```

## 注意点

- `Loading` バウンダリ内の非同期読み取りはフォールバックを出力します。出力に確定済みデータを含める必要がある場合は `renderToStream` を await してください。
- 結果はクライアントで `hydrate()` と組み合わせてください。複数のルートがページを共有する場合は、両者で `renderId` を一致させてください。
