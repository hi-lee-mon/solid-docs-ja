Solid コンポーネントツリーをサーバーレンダーされた DOM にアタッチし、ハイドレートされたツリーを破棄する関数を返します。

## インポート

```ts
import { hydrate } from "@solidjs/web";
```

## 型シグネチャ

```ts
function hydrate(
	fn: () => JSX.Element,
	node: MountableElement,
	options?: { renderId?: string; owner?: unknown }
): () => void;
```

## パラメータ

### `fn`

- **型:** `() => JSX.Element`

サーバーがレンダーしたのと同じルート JSX を返す関数。

### `node`

- **型:** `MountableElement`

サーバーレンダーされたマークアップを含む DOM ノード。

### `options`

- **型:** `{ renderId?: string; owner?: unknown; onError?: ClientErrorHook }`
- オプション

サーバーでレンダー ID が設定されていた場合、`renderId` はそれと一致する必要があります。`owner` はルートを既存のオーナーの下に親付けします。

## 戻り値

ハイドレートされたツリーの破棄関数。

## 例

```tsx
import { hydrate } from "@solidjs/web";

const dispose = hydrate(() => <App />, document.getElementById("root")!);
```

## 注意点

- クライアントはサーバーと同じツリーをレンダーする必要があります。不一致があると、開発環境でハイドレーションエラーが報告されます。
- `Portal` 内のコンテンツはクライアントで新しくレンダーされます。サーバーはそれに対して何も出力しません。
