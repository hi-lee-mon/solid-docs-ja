開発用出力では `true`、本番用出力では `false` になるビルド時定数です。

## インポート

```ts
import { isDev } from "@solidjs/web";
```

## 型シグネチャ

```ts
const isDev: boolean;
```

## 例

```ts
import { isDev } from "@solidjs/web";

if (isDev) {
  console.warn("debug-only path");
}
```

```ts
if (isDev) {
	console.warn("Development-only diagnostic");
}
```

## 注意点

- これはビルド時定数です。`if (isDev)` の内側のコードは本番用出力から削除されます。
