ブラウザでのみレンダーされるコンポーネントを作成します。サーバーはフォールバックをレンダーし、クライアントはインポートされたコンポーネントをマウントするまで、ハイドレーションを通じてそのフォールバックを維持します。

> サポートされているバンドラー変換を使うと、サーバーレンダリングでコンポーネントの JavaScript と CSS のプリロードヒントを出力できます。サーバーはインポーターを実行せず、インポートされたコンポーネントもレンダーしません。

## インポート

```ts
import { clientOnly } from "@solidjs/web";
```

## 型シグネチャ

```ts
function clientOnly<M extends Record<string, any>, K extends keyof M & string>(
	fn: () => Promise<M>,
	options: { lazy?: boolean; export: K }
): Component<ComponentProps<M[K]> & { fallback?: JSX.Element }>;
function clientOnly<T extends Component<any>>(
	fn: () => Promise<{ default: T }>,
	options?: { lazy?: boolean; export?: string }
): Component<ComponentProps<T> & { fallback?: JSX.Element }>;
```

## パラメータ

### `fn`

- **型:** `() => Promise<M> | () => Promise<{ default: T }>`

コンポーネントのモジュールを解決する動的インポート。

### `options`

- **型:** `{ lazy?: boolean; export: K } | { lazy?: boolean; export?: string }`
- オプション

`export` はどのエクスポートがコンポーネントかを指定します。`lazy` はクライアントですぐにインポートを開始する代わりに、初回レンダーまでインポートを遅延します。

### `moduleUrl`

- **型:** `string`
- オプション

バンドラーインテグレーションによって注入されるモジュール指定子。プリロードヒントとエラーメッセージに使われます。

## 戻り値

インポートされたコンポーネントの props に、オプションの `fallback` を加えたコンポーネント。

## 例

```tsx
const Chart = clientOnly(() => import("./Chart.jsx"));
// <Chart fallback={<div>Loading chart…</div>} data={data()} />
```

## 注意点

- サーバーはフォールバックのみをレンダーし、クライアントはコンポーネントをマウントするまでハイドレーションを通じてそれを維持します。
- インポートされたコンポーネント内の非同期読み取りはクライアントで開始されます。サーバーでフェッチすべきデータはバウンダリより上に移動してください。
