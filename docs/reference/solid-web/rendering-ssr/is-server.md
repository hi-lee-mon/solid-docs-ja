サーバー出力では `true`、ブラウザ出力では `false` になるビルド時定数です。

## インポート

```ts
import { isServer } from "@solidjs/web";
```

## 型シグネチャ

```ts
const isServer: boolean;
```

## 例

```ts
import { isServer } from "@solidjs/web";

if (!isServer) {
  // Browser-only: tree-shaken out of the SSR bundle.
  window.addEventListener("resize", onResize);
}
```

```ts
if (!isServer) {
	window.addEventListener("resize", onResize);
}
```

## 注意点

- これはビルド時定数です。`if (!isServer)` の内側のコードはサーバーバンドルから削除されるため、`typeof window` チェックではなくこちらを使ってください。
