コンポーネントツリーを DOM 要素にレンダーします。呼び出すとツリーを
解体してリアクティブスコープをクリーンアップする破棄関数を返します。

トップレベルの挿入は `{ schedule: true }` でキューに入れられるため、
最初の DOM アタッチはインラインで実行されずエフェクトキューを経由します。
これによりマウントは保留中の更新に参加できます。初回レンダー中に
捕捉されない非同期読み取りが表面化した場合（それを吸収する
`Loading` 祖先がない場合）、マウントは保留され、すべての保留が
確定した時点でアトミックにアタッチされます。非同期がない正常パスでは、
末尾の `flush()` がキューに入ったコールバックを排出するため、
`render()` が戻るまでにアタッチは同期的に完了します。開発時の
強制ウィンドウは `ASYNC_OUTSIDE_LOADING_BOUNDARY` を初回マウントのみに
スコープします。

## インポート

```ts
import { render } from "@solidjs/web";
```

## 型シグネチャ

```ts
function render(
  code: () => JSX.Element,
  element: MountableElement,
  init?: JSX.Element,
  options?: {
    owner?: unknown;
    renderId?: string;
    /**
     * This root's client error hook, ahead of `configureClientErrors`':
     * every failure an error boundary under it renders a fallback for —
     * the one event no global handler sees (an uncaught error halts the
     * reactive system and reaches `reportError` / `window.onerror`). Once
     * per error object; no return — the client has no wire to map for.
     */
    onError?: ClientErrorHook;
  }
): () => void;
```

## パラメータ

### `code`

- **型:** `() => JSX.Element`

ルート JSX を返す関数。新しいリアクティブルート内で一度だけ実行されます。

### `element`

- **型:** `MountableElement`

マウント先の DOM ノード。ツリーはその子要素として挿入されます。

### `init`

- **型:** `JSX.Element`
- オプション

初期の子要素として再利用する既存のコンテンツ。例えば静的シェルからのもの。

### `options`

- **型:** `{ owner?: unknown; renderId?: string; onError?: ClientErrorHook; }`
- オプション

新しいルートを既存のオーナーの下に親付けする `owner` と、ハイドレーション ID プレフィックス用の `renderId`。

## 戻り値

破棄関数。呼び出すとレンダーされた DOM を削除し、リアクティブルートを破棄します。

## 例

### アプリをマウントする

```tsx
// src/entry-client.tsx
import { render } from "@solidjs/web";
import App from "./App";

const dispose = render(() => <App />, document.getElementById("root")!);
```

### テストでアンマウントする

```tsx
const container = document.createElement("div");
const dispose = render(() => <Counter />, container);

// ...assert against container...

dispose(); // removes the DOM and disposes the reactive root
```

## 注意点

- `render` はリアクティブルートを作成します。その外側（モジュールスコープ）でリアクティブプリミティブを呼び出してもオーナーがなく、破棄もされません。
- すでにサーバー HTML を持つ要素へのレンダーはそれを再利用しません。サーバーレンダーされたページには `hydrate` を使ってください。
