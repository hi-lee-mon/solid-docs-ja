リストから要素のリストを生成します。

子としてマップ関数を受け取り、リストの各項目に対して JSX 要素を
返します。リストが空の場合は、省略可能な `fallback` が代わりに
レンダーされます。

子コールバックの引数の形はキー指定モードによって変わります:
- デフォルト / `keyed={true}` では `(item, index)` を受け取り、
  `item` は生の行の値、`index` はアクセサーです。
- `keyed={false}` では `(item, index)` を受け取り、`item` は
  アクセサー、`index` は安定した数値です。
- `keyed={(item) => key}` では、両方の引数がアクセサーとして
  渡されます。

## Props

### `each`

- **型:** `T | undefined | null | false`

レンダー対象の配列。falsy な値の場合は fallback がレンダーされます。

### `fallback`

- **型:** `JSX.Element`
- 省略可能

配列が空または falsy のときにレンダーされます。

### `keyed`

- **型:** `true | false | ((item) => any)`
- 省略可能

行の同一性。デフォルトの `true` はアイテムの参照でキー付けし、生のアイテムとアクセサーの index を渡します。`false` は位置でキー付けし、アイテムのアクセサーと安定した index を渡します。関数の場合はその戻り値でキー付けし、両方ともアクセサーを渡します。

### `children`

- **型:** `(item, index) => JSX.Element`

行のレンダラー。引数の形は `keyed` に従います。上記を参照してください。

## 例

```tsx
<For each={items} fallback={<div>No items</div>}>
  {(item, index) => <div data-index={index()}>{item.label}</div>}
</For>
```

### フィールドで行にキーを付ける

```tsx
// Rows keep their DOM when the server returns new objects for the same ids.
<For each={todos()} keyed={(todo) => todo.id}>
	{(todo, index) => (
		<li>
			{index() + 1}. {todo().text}
		</li>
	)}
</For>
```

## 注意点

- デフォルトの `keyed` はアイテムの参照で行をキー付けします。同じデータでも新しいオブジェクトインスタンスだと行が再生成されます。安定した `keyed` 関数かストアで行の同一性を保ってください。
- `each` には配列または falsy な値を渡します。アクセサーではなくアクセサーの値（`each={items()}`）を渡してください。
