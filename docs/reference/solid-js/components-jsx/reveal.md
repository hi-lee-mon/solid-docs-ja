兄弟の `<Loading>` バウンダリの表示タイミングを調整します。

`order` prop で表示ポリシーを選択します:
- `"sequential"`（デフォルト）— バウンダリは登録順に表示されます。
  後のバウンダリは、先のバウンダリが解決するまで fallback のままに
  なります。
- `"together"` — グループ全体が「最小限の準備完了」（すべての直接
  スロットが最初の表示コンテンツを利用可能な状態）になるまで、すべての
  直接スロットが fallback のままになり、その後グループが一体となって
  一斉に表示されます。
- `"natural"` — 各バウンダリは自身のデータが解決し次第表示されます。
  トップレベルでは `<Reveal>` を省略した場合と同等です。このモードは
  ネスト用で、グループは外側の `<Reveal>` 内で1つの複合スロットとして
  登録されます。

`collapsed` prop は `order="sequential"`（デフォルト）の場合にのみ
参照され、`"together"` と `"natural"` では無視されます。設定すると、
先端を超えた後続のバウンダリは自身の fallback 出力を抑制します。

ネストされた `<Reveal>` グループは合成されます。内側のグループは外側の
順序の1つのスロットとなり、外側がそのスロットを解放するまで fallback
のまま保持されます。解放後、内側のグループは残っている保留中のものに
対して自身の `order` をローカルに実行します。逃げ道はありません。
外側のグループの下にネストするということは、その順序付けに参加する
ことを意味します。

function Reveal(props: RevealProps): JSX.Element;

## Props

### `order`

- **型:** `RevealOrder`
- 省略可能

`"sequential"`（デフォルト）、`"together"`、または `"natural"`。各ポリシーについては概要を参照してください。

### `collapsed`

- **型:** `boolean`
- 省略可能

`"sequential"` の場合にのみ参照されます。先端を超えたバウンダリは fallback の代わりに何もレンダーしません。

### `children`

- **型:** `JSX.Element`

調整対象となる `Loading` バウンダリ（またはネストされた `Reveal` グループ）。

## 例

```tsx
// Default order is "sequential"; the inner group composes as one slot
// and runs its own "natural" order locally once the outer releases it.
<Reveal>
  <Loading fallback={<Skeleton />}><ProfileHeader /></Loading>
  <Reveal order="natural">
    <Loading fallback={<Skeleton />}><PostA /></Loading>
    <Loading fallback={<Skeleton />}><PostB /></Loading>
  </Reveal>
  <Loading fallback={<Skeleton />}><Comments /></Loading>
</Reveal>
```

## 注意点

- ネストされたグループは常に外側のグループの順序付けに参加します。不参加にする方法はありません。
- `collapsed` は `"together"` や `"natural"` では効果がありません。
