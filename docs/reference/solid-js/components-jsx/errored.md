サブツリー内で捕捉されなかったエラーをキャッチし、代わりに
fallback コンテンツをレンダーします。`fallback` prop には
JSX 要素か、エラーと再試行のための `reset()` 関数を受け取る
コールバックを渡せます。

fallback 自体からスローされたエラーは、親の `<Errored>` で
捕捉できます。

## インポート

```ts
import { Errored } from "solid-js";
```

## 型シグネチャ

```ts
function Errored(props: {
  fallback: JSX.Element | ((err: ErrorAccessor, reset: () => void) => JSX.Element);
  children: JSX.Element;
}): JSX.Element;
```

## Props

### `fallback`

- **型:** `JSX.Element | ((err: ErrorAccessor, reset: () => void) => JSX.Element)`

サブツリーの代わりにレンダーするコンテンツ、またはエラーのアクセサーとサブツリーを再試行する `reset()` 関数を受け取る関数。

### `children`

- **型:** `JSX.Element`

保護するサブツリー。

## 例

```tsx
<Errored fallback={(err, reset) => (
  <div onClick={reset}>Error: {err().toString()}</div>
)}>
  <MyComp />
</Errored>
```

## 注意点

- このバウンダリは、サブツリーのレンダー中にスローされたエラーと、reject された非同期読み取りを含むリアクティブグラフを伝播してきたエラーを捕捉します。イベントハンドラー内のエラーは、その場で処理してください。
- `reset()` は失敗したソースを再計算します。原因が残っていれば、バウンダリは再びエラーになります。
- fallback 自体からスローされたエラーは、親の `Errored` に送られます。
