個数から要素のリストを生成します。

子として、index を受け取って JSX 要素を返すマップ関数を受け取り
ます。個数がゼロの場合は、省略可能な `fallback` が代わりに
レンダーされます。

> `Repeat` はストア上での位置ベースのリストレンダリングです。配列のアイテムや同一性を差分比較せず、数値の index から行を生成するため、ストアの読み取りは細粒度のまま保たれます。`from` と `count` を組み合わせるとスライドウィンドウになり、重なった範囲の行は保持されます。

## インポート

```ts
import { Repeat } from "solid-js";
```

## 型シグネチャ

```ts
function Repeat<T extends JSX.Element>(props: {
  count: number;
  from?: number | undefined;
  fallback?: JSX.Element;
  children: ((index: number) => T) | T;
}): JSX.Element;
```

## Props

### `count`

- **型:** `number`

行数。

### `from`

- **型:** `number | undefined`
- 省略可能

先頭行の index。`count` と組み合わせると、より大きなリスト上のウィンドウになります。

### `fallback`

- **型:** `JSX.Element`
- 省略可能

`count` がゼロのときにレンダーされます。

### `children`

- **型:** `((index: number) => T) | T`

index からコンテンツへの関数、または各 index で繰り返される静的コンテンツ。

## 例

```tsx
<Repeat count={items.length} fallback={<div>No items</div>}>
  {(index) => <div data-index={index}>{items[index]}</div>}
</Repeat>
```

## 注意点

- 行は位置ベースです。ソースの途中にアイテムを挿入すると、それ以降のすべての行が読み取るデータがずれます。行に同一性がある場合は `For` を使ってください。
