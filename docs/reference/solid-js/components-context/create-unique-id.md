サーバーでレンダーされたツリーとクライアントでハイドレートされた
ツリーの間で一致する、安定した id 文字列を返します。`<label for>` や
`aria-labelledby` など、SSR 全体で一貫した id が必要な属性に
使います。

## インポート

```ts
import { createUniqueId } from "solid-js";
```

## 型シグネチャ

```ts
function createUniqueId(): string;
```

## 戻り値

サーバーでレンダーされたツリーとハイドレートされたツリーとで一致する文字列 id。

## 例

```tsx
function Field(props: { label: string }) {
  const id = createUniqueId();
  return (
    <>
      <label for={id}>{props.label}</label>
      <input id={id} />
    </>
  );
}
```

## 注意点

- サーバーとクライアントが同じ id を生成できるよう、コンポーネントの本体または別のオーナー付きスコープで呼び出してください。
