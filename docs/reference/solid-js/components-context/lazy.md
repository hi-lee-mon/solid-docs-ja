コード分割されたコンポーネントを定義します。返されるコンポーネントは
最初のレンダーで動的インポートを開始し、チャンクの取得中は外側に
ある `<Loading>` バウンダリを通じてサスペンドします。`.preload()` を
呼ぶとインポートを早めに開始できます（例：ホバー時）。

## インポート

```ts
import { lazy } from "solid-js";
```

## 型シグネチャ

```ts
function lazy<M extends Record<string, any>, K extends keyof M & string>(
  fn: () => Promise<M>,
  options: { export: K },
  moduleUrl?: string
): M[K] & { preload: () => Promise<M>; moduleUrl?: string };
function lazy<T extends Component<any>>(
  fn: () => Promise<{ default: T }>,
  options?: { export?: string },
  moduleUrl?: string
): T & { preload: () => Promise<{ default: T }>; moduleUrl?: string };
```

## パラメータ

### `fn`

- **型:** `() => Promise<M> | () => Promise<{ default: T }>`

コンポーネントのモジュールを解決する動的インポート。

### `options`

- **型:** `{ export: K } | { export?: string }`
- 省略可能

`{ export }` でモジュールのどのエクスポートがコンポーネントかを指定します。デフォルトは `default` です。

### `moduleUrl`

- **型:** `string`
- 省略可能

バンドラー連携によって注入されるモジュール指定子。コンポーネントの `moduleUrl` プロパティとして公開され、ハイドレーションのエラーメッセージで使われます。

## 戻り値

インポートしたコンポーネントと同じ props を持つコンポーネント。インポートを早めに開始する `preload()` メソッドも付いています。

## 例

```tsx
const Profile = lazy(() => import("./Profile"));
const About = lazy(() => import("./pages"), { export: "About" });

function App() {
  return (
    <Loading fallback={<Spinner />}>
      <Profile id="42" />
    </Loading>
  );
}

// Preload before the user clicks
<button onMouseEnter={() => Profile.preload()}>Open profile</button>
```

## 注意点

- インポートは定義時ではなく最初のレンダーで実行されます。コンポーネントを `Loading` バウンダリで包まないと、最も近いバウンダリが fallback を表示します。
- デフォルトでは、コンポーネントはモジュールの default エクスポートである必要があります。名前付きエクスポートには `{ export: "Name" }` を使います。エクスポートを1つ選ぶランタイムラッパーはハイドレーションを壊します。
