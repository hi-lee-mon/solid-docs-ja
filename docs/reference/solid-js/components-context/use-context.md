コンテキストの現在値を読み取ります。

- `createContext<T>()`（デフォルト値なし）の場合：最も近い外側の
  Provider の値を返します。Provider がマウントされていなければ
  `ContextNotFoundError` をスローします。戻り値の型は `T` です
  （絞り込みは不要）。
- `createContext<T>(defaultValue)` の場合：最も近い外側の
  Provider の値を返します。Provider がマウントされていなければ
  `defaultValue` を返します。

Solid では `useContext` がコンテキストを読み取る標準的な方法です。
Provider がないときにスローするラッパーフックは必要ありません。
デフォルト値なしの形式がすでにそれを行い、戻り値の型も `T` になる
からです。

## インポート

```ts
import { useContext } from "solid-js";
```

## 型シグネチャ

```ts
function useContext<T>(context: Context<T>): T;
```

## パラメータ

### `context`

- **型:** `Context<T>`

`createContext` が返すコンテキスト。

## 戻り値

最も近い外側の Provider が提供した値。`createContext` に
デフォルト値が渡されている場合はそのデフォルト値。

## 例

```tsx
const TodosContext = createContext<TodosCtx>();

function TodoList() {
  const [todos, { addTodo }] = useContext(TodosContext); // throws if no Provider
  // ...
  return null;
}
```

## 注意点

- コンポーネントの本体または別のオーナー付きスコープで呼び出してください。イベントハンドラー内や `await` の後に呼び出すと、読み取り元のオーナーがありません。
- 値は最も近い Provider が渡したものです。リアクティブ性を保つには、現在値ではなくシグナルやストアを渡してください。
