コンポーネントツリー内で、Provider の子孫と状態を共有するための
コンテキストを作成します。

返される `Context` はそれ自体がプロバイダーコンポーネントです。
`value` prop を渡すと、その値が子のスコープに設定されます。
子孫の中では `useContext` で読み取ります。

2つの形式があります:

- **`createContext<T>()`**（デフォルト値なしの、標準的な形式）。
  外側に Provider がない状態で `useContext` で読み取ると
  `ContextNotFoundError` をスローします。リアクティブな状態を運ぶ
  ものすべて、つまりシグナル・ストア・`[state, actions]` タプル・
  サービスにはこの形式を使います。Provider は構造的に必須であり、
  スローによって Provider の欠落が静かな no-op ではなく明示的な
  バグになります。推論元になる値がないため、`<T>` のアノテーション
  が必須です。
- **`createContext<T>(defaultValue)`**（デフォルト値ありの形式）。
  値がプリミティブで、意味のある静的フォールバックを持つコンテキスト
  （テーマ・ロケール・固定設定）という限定的なケースにのみ使います。
  どの Provider の外でも、`useContext` は `defaultValue` を返します。

コンテキストはサブツリーに属する状態のためのものです。これには、
サーバーでレンダーされるアプリにおけるアプリ全体の状態も含まれます。
コンポーネント内で作成された値はリクエストごとに一度だけ作成され、
Provider がそれを所有・破棄します。モジュールスコープは同じプロセス
内のすべてのリクエストで共有されるため、定数専用にしてください。

## インポート

```ts
import { createContext } from "solid-js";
```

## 型シグネチャ

```ts
function createContext<T>(defaultValue?: T, options?: EffectOptions): Context<T>;
```

## パラメータ

### `defaultValue`

- **型:** `T`
- 省略可能

省略可能なデフォルト値。プリミティブなフォールバックの場合にのみ意味を持ちます。リアクティブな状態を運ぶコンテキストでは省略し、Provider がないときにスローされるようにしてください。

### `options`

- **型:** `EffectOptions`
- 省略可能

開発時のデバッグ用に `{ name }` を指定できます。

## 戻り値

それ自体がプロバイダーコンポーネントとしても機能するコンテキストオブジェクト。

## 例

```tsx
// Reactive payload — default-less, throws if no Provider.
type TodosCtx = readonly [Store<Todo[]>, TodoActions];
const TodosContext = createContext<TodosCtx>();

function App() {
  return (
    <TodosContext value={createTodos()}>
      <TodoList />
    </TodosContext>
  );
}

function TodoList() {
  const [todos, { addTodo }] = useContext(TodosContext); // typed as TodosCtx
  // ...
  return null;
}
```

```tsx
// Primitive default — falls back to "light" outside a Provider.
const ThemeContext = createContext<"light" | "dark">("light");

function Button() {
  const theme = useContext(ThemeContext); // "light" | "dark"
  return <button class={theme}>Click</button>;
}
```

## 注意点

- デフォルト値がない場合、Provider の外で読み取ると `ContextNotFoundError` をスローします。これは意図的な動作です。デフォルト値を追加するのはプリミティブなフォールバックの場合だけにしてください。
- アプリ全体の状態であれば、モジュールスコープのシグナルやストアは既にグローバルです。コンテキストは値をサブツリーにスコープするためのものです。
