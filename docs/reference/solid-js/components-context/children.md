`children` アクセサーを解決し、その結果を `.toArray()` ヘルパー付きの
アクセサーとして公開します。コンポーネントが children をそのまま
レンダーするだけでなく、内容を調べたり反復処理したりする必要がある
場合に使います。

## インポート

```ts
import { children } from "solid-js";
```

## 型シグネチャ

```ts
function children(fn: Accessor<JSX.Element>): ChildrenReturn;
```

## パラメータ

### `fn`

- **型:** `Accessor<JSX.Element>`

生の children へのアクセサー。通常は `() => props.children` を渡します。

## 戻り値

解決済みの children を返すアクセサー。反復処理には `.toArray()` を使います。

## 例

```tsx
function List(props: { children: Element }) {
  const items = children(() => props.children);
  return <ul>{items.toArray().map(item => <li>{item}</li>)}</ul>;
}
```

## 注意点

- コンポーネントの本体で一度だけ呼び出し、その結果を読み取ってください。`props.children` を複数箇所で呼び出すと、children がその都度生成されます。
- アクセサーは遅延評価で解決されます。最初の読み取りは、結果が挿入される場所か `toArray()` が呼び出された時点で行われます。
