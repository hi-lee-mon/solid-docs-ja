汎用の `Component` は暗黙の `children` prop を持ちません。必要なら
`Component<{ name: string; children: Element }>` のように
明示的に指定してください。

## インポート

```ts
import type { Component, ComponentProps, FlowComponent, FlowProps, ParentComponent, ParentProps, Ref, ValidComponent, VoidComponent, VoidProps } from "solid-js";
```

## `Component`

### 型シグネチャ

```ts
type Component<P extends Record<string, any> = {}> = (props: P) => JSX.Element;
```

## `ComponentProps`

渡されたコンポーネントの props を取り出してその型を返します。

組み込み（intrinsic）要素の props の抽出はレンダラー固有のもので、
`@solidjs/web` などのレンダラーパッケージに存在します。

### 型シグネチャ

```ts
type ComponentProps<T extends ValidComponent> = T extends Component<infer P> ? P : never;
```

## `FlowComponent`

`FlowComponent` は指定した型の `children` prop を必須にします。
特定の子の型が必要なコンポーネント、典型的には特定の引数型を
受け取る関数を子に取る場合に使います。

### 型シグネチャ

```ts
type FlowComponent<P extends Record<string, any> = {}, C = JSX.Element> = Component<
  FlowProps<P, C>
>;
```

## `FlowProps`

指定した型の `children` prop を必須にするよう props を拡張します。
特定の子の型が必要なコンポーネント、典型的には特定の引数型を
受け取る関数を子に取る場合に使います。

### 型シグネチャ

```ts
type FlowProps<P extends Record<string, any> = {}, C = JSX.Element> = P & { children: C };
```

## `ParentComponent`

`ParentComponent` は省略可能な `children` prop を許可します。
children を受け取りたいコンポーネントに使います。

### 型シグネチャ

```ts
type ParentComponent<P extends Record<string, any> = {}> = Component<ParentProps<P>>;
```

## `ParentProps`

省略可能な Solid の children を許可するよう props を拡張します。
children を受け取りたいコンポーネントに使います。

### 型シグネチャ

```ts
type ParentProps<P extends Record<string, any> = {}> = P & { children?: JSX.Element };
```

## `Ref`

`props.ref` の型。`Component` や `props` の型付けで使います。

### 型シグネチャ

```ts
type Ref<T> = T | ((val: T) => void) | undefined | Ref<T>[];
```

### 例

```ts
Component<{ref: Ref<Element>}>
```

## `ValidComponent`

ValidComponent の API リファレンスです。

### 型シグネチャ

```ts
type ValidComponent = Component<any>;
```

## `VoidComponent`

`VoidComponent` は `children` prop を禁止します。
受け取った `children` を黙って捨ててしまうコンポーネントへ
`children` を誤って渡すのを防ぐために使います。

### 型シグネチャ

```ts
type VoidComponent<P extends Record<string, any> = {}> = Component<VoidProps<P>>;
```

## `VoidProps`

`children` prop を禁止するよう props を拡張します。
受け取った `children` を黙って捨ててしまうコンポーネントへ
`children` を誤って渡すのを防ぐために使います。

### 型シグネチャ

```ts
type VoidProps<P extends Record<string, any> = {}> = P & { children?: never };
```
