`createOptimistic` のストア版。`action` トランジション内での
書き込みは暫定的です — 即座に反映されますが、トランジションが
終了すると自動的に差し戻されます（またはアクションの解決値に
調整されます）。

コレクション形状のデータへの楽観的 UI に使ってください。
単一値の楽観的な状態には `createOptimistic` を優先してください。

- **プレーン形式** — `createOptimisticStore(initialValue, options?)`。
- **派生形式** — `createOptimisticStore(fn, seed, options?)`:
  権威ある値が `fn` で再計算され、楽観的オーバーレイが各アクション後に
  差し戻されるプロジェクションストアです。

派生形式では `options.key` のデフォルトは `"id"` です。データが別の
識別フィールドを使う場合（例: `{ key: "uuid" }` や
`{ key: t => t.slug }`）にのみ指定してください。デフォルトを
書き直すとノイズが増えるだけです。

## インポート

```ts
import { createOptimisticStore } from "solid-js";
```

## 型シグネチャ

```ts
function createOptimisticStore<T extends object = {}>(
  initialValue: T | Store<T>,
  options?: StoreOptions
): [get: Store<T>, set: StoreSetter<T>];
function createOptimisticStore<T extends object = {}>(
  fn: (draft: T) => void | T | Promise<void | T> | AsyncIterable<void | T>,
  seed: Partial<T> | Store<T>,
  options?: ProjectionOptions
): [get: Store<T>, set: StoreSetter<T>];
```

## パラメータ

### `initialValue`

- **型:** `T | Store<T>`

ラップするプレーンなオブジェクトまたは配列。

### `options`

- **型:** `StoreOptions | ProjectionOptions`
- 省略可能

プレーン形式では `name` と `shallow`。派生形式では `key`、`seedLoadingValue`、`deferStream`、`ssrSource` も受け付けます。

### `fn`

- **型:** `(draft: T) => void | T | Promise<void | T> | AsyncIterable<void | T>`

権威ある内容を生成する派生関数。楽観的な書き込みはその結果にオーバーレイされ、アクションが確定すると差し戻されます。

### `seed`

- **型:** `Partial<T> | Store<T>`

派生形式の初期内容。

## 戻り値

`[store: Store<T>, setStore: StoreSetter<T>]`

`createStore` と同じ形のタプル。アクション内で行われた書き込みは暫定的で、アクションが確定すると差し戻されます。

## 例

```ts
const [todos, setTodos] = createOptimisticStore<Todo[]>([]);

// Mutation: optimistic add, then in-place reconcile to the saved row.
const addTodo = action(function* (text: string) {
  const tempId = crypto.randomUUID();
  setTodos(t => { t.push({ id: tempId, text, pending: true }); });
  const saved = yield api.createTodo(text);
  setTodos(t => {
    const i = t.findIndex(x => x.id === tempId);
    if (i >= 0) t[i] = saved;
  });
});

// Return form: filter is the natural shape for removal.
const removeTodo = action(function* (id: string) {
  setTodos(t => t.filter(x => x.id !== id));
  yield api.removeTodo(id);
});
```

**ハイドレーション:** 派生形式では `ssrSource` フィールド
（`"server"` | `"hybrid"` | `"client"`）を含む `ProjectionOptions` を
受け付けます。`ssrSource` オプションを参照してください。

## 注意点

- 楽観的な書き込みは `action` 内で行ってください。オーバーレイを差し戻す、または解決値に調整するトリガーはアクションの確定です。
- 保持するには、保存済みの行をアクション内でドラフトに書き込んでください。オーバーレイ自体は持続しません。
- 派生形式では `key` のデフォルトは `"id"` です。識別フィールドが異なる場合に設定してください。
