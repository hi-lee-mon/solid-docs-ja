複数の props 風オブジェクトを、*リアクティビティを保つ* 単一の
プロキシにマージします。読み取りは、そのプロパティを定義している
最も右側のソースへ転送されるため、後のソースが前のソースを上書き
します（`Object.assign` と同様です）。

関数の引数はメモをバックにしたソースとして扱われます。リアクティブに
追跡すべき計算による派生デフォルト値を渡すのに便利です。

結果はソースのライブなビューであり、決してコピーではありません:
作成時にキーごとのコストはかからず、すべての読み取りはそのキーを
所有するソースに向かい（ゲッターはそこで実行され、データプロパティ
はライブに読み取られます）、書き込みは no-op です。関数でない
ソースが 1 つだけの場合はそのまま返されます。ミュータブルな
オブジェクトを所有したい場合はコピーしてください:
`{ ...merged }` は現在値のスナップショットを取ります。

コンポーネント本体内で、Solid のプロパティごとの追跡を失わずに
デフォルト値とオーバーライドをマージするために使います。

## インポート

```ts
import { merge } from "solid-js";
```

## 型シグネチャ

```ts
function merge<T extends unknown[]>(...sources: T): Merge<T>;
```

## パラメータ

### `sources`

- **型:** `T`

props 風オブジェクト、またはそれを返す関数。後のソースが前のソースを上書きします。

## 戻り値

マージされたソースのリアクティブなプロキシ。プロパティの読み取りは、それを供給するソースを追跡します。

## 例

```tsx
function Button(_props: { label: string; type?: string; disabled?: boolean }) {
  const props = merge({ type: "button", disabled: false }, _props);

  return <button type={props.type} disabled={props.disabled}>{props.label}</button>;
}
```

## 注意点

- 結果を分割代入しないでください。プロキシを通してプロパティを読み取ることが、リアクティビティを保つ仕組みです。
- 関数のソースはメモをバックにしたソースとして扱われるため、その計算は追跡されます。それが意図でない場合はプレーンなオブジェクトを渡してください。
