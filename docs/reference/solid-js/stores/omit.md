指定したキーを隠した `props` のリアクティブなプロキシを返します。
残りのキーの追跡は維持されます。

コンポーネント自身が扱うキーを取り除きながら、残りの「rest」props を
子要素へ転送するために使います。`splitProps(p, ["a","b"])[1]` と
同等です。

結果は `props` のライブなビューであり、コピーではありません:
キーが使われるまで何も読み取られず、実体化もされません。スプレッド
（`{...rest}`）や後続の `merge()` は元のオブジェクトを直接
たどります。述語を使うと、名前ではなくルールでキーを隠せます —
`omit(props, k => k[0] === "$")` — 事前に列挙する必要は
ありません。

## インポート

```ts
import { omit } from "solid-js";
```

## 型シグネチャ

```ts
function omit<T extends Record<any, any>, K extends readonly (keyof T)[]>(
  props: T,
  ...keys: K
): Omit<T, K>;
function omit<T extends Record<any, any>>(
  props: T,
  hidden: (key: keyof T & (string | symbol)) => boolean
): Partial<T>;
```

## パラメータ

### `props`

- **型:** `T`

読み取り元の props オブジェクト。

### `keys`

- **型:** `K`

返されるプロキシから隠すプロパティ名。

### `hidden`

- **型:** `(key: keyof T & (string | symbol)) => boolean`

## 戻り値

指定したキーを除いた `props` のリアクティブなプロキシ。

## 例

```tsx
function Input(props: { label: string; value: string; onInput: (v: string) => void } & JSX.HTMLAttributes<HTMLInputElement>) {
  const rest = omit(props, "label", "value", "onInput");

  return (
    <label>
      {props.label}
      <input
        {...rest}
        value={props.value}
        onInput={e => props.onInput(e.currentTarget.value)}
      />
    </label>
  );
}
```

## 注意点

- 結果を分割代入しないでください。要素にスプレッドするか、プロキシを通してプロパティを読み取ってください。
- キーは一度だけ評価されます。動的なキーの集合を隠したい場合は、ラッパーオブジェクトを作ってください。
