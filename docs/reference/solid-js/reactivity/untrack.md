`fn` をあらゆるリアクティブな追跡の外で実行します — `fn` 内での
読み取りは現在のスコープを購読させません。`fn` が返すものをそのまま返します。

将来の変更に周囲の計算を依存させずに、シグナルを一度だけ読み取る必要が
あるときに、メモやエフェクトの中で `untrack` を使います。

`strictReadLabel` 文字列を渡すと開発モードの警告が有効になります:
`fn` 内で、ネストされた追跡スコープの外で行われたリアクティブな読み取りは
すべて、そのラベル名を挙げた警告をログに出力します。

## インポート

```ts
import { untrack } from "solid-js";
```

## 型シグネチャ

```ts
function untrack<T>(fn: () => T, strictReadLabel?: string | false): T;
```

## パラメータ

### `fn`

- **型:** `() => T`

追跡なしで実行する関数。その戻り値が返されます。

### `strictReadLabel`

- **型:** `string | false`
- 省略可能

設定すると、開発ビルドで `fn` 内のリアクティブな読み取りについて警告し、警告にそのラベル名を表示します。

## 戻り値

`fn` が返す値。

## 例

```ts
createEffect(
  () => trigger(),                 // tracks `trigger` only
  () => {
    const snapshot = untrack(() => state); // read once, untracked
    log(snapshot);
  }
);
```

## 注意点

- 読み取りをアントラックしても、他の追跡された読み取りによる計算の再実行は止まりません。
- エフェクト内では 2 フェーズ形式を優先してください: `effectFn` 内の読み取りはすでにアントラックされています。
