楽観的シグナルを作成します。これは `action` 内での書き込みが
暫定的になる `Signal<T>` です: 書き込みは即座に反映され、
保留中の処理が確定すると自動的に差し戻されます（または
アクションの解決値に調整されます）。

単一値の楽観的な状態に使います。コレクション形状の状態には
`createOptimisticStore` を優先してください。

- **プレーン形式** — `createOptimistic(value, options?: SignalOptions<T>)`。
- **関数形式** — `createOptimistic(fn, options?: SignalOptions<T> & MemoOptions<T>)`:
  権威ある値は `fn` によって再計算され、楽観的オーバーレイは
  各アクション後に差し戻されます。

## インポート

```ts
import { createOptimistic } from "solid-js";
```

## 型シグネチャ

```ts
function createOptimistic<T>(): Signal<T | undefined>;
function createOptimistic<T>(value: Exclude<T, Function>, options?: SignalOptions<T>): Signal<T>;
function createOptimistic<T>(
  fn: ComputeFunction<NoInfer<T>, T>,
  options: SignalOptions<T> & MemoOptions<T> & { loadingValue: T }
): Signal<T>;
function createOptimistic<T>(
  fn: ComputeFunction<undefined | NoInfer<T>, T>,
  options?: SignalOptions<T> & MemoOptions<T>
): Signal<T>;
```

## パラメータ

### `value`

- **型:** `Exclude<T, Function>`

権威あるシグナルの初期値。

### `options`

- **型:** `SignalOptions<T>`
- 省略可能

デバッグ用の `name` と `equals` 比較関数。関数形式では `MemoOptions<T>` も受け付けます。

### `fn`

- **型:** `ComputeFunction<T | undefined, T>`

派生形式の compute 関数。権威ある値を生成します。楽観的な書き込みはそれにオーバーレイされ、アクションが確定すると差し戻されます。

## 戻り値

`[state: Accessor<T>, setState: Setter<T>]`

`createSignal` と同じ形のタプル。アクション内で行われた書き込みは暫定的で、アクションが確定すると差し戻されます。

## 例

```ts
const [name, setName] = createOptimistic("Ada");

const rename = action(function* (next: string) {
  setName(next);                 // optimistic
  yield api.rename(next);        // commits or reverts on settle
});
```

**ハイドレーション:** 関数形式では `ssrSource` フィールド
（`"server"` | `"hybrid"` | `"client"`）を受け付けます。`ssrSource` オプションを参照してください。

## 注意点

- 楽観的な書き込みは `action` 内で行ってください。オーバーレイを差し戻す、または解決値に調整するトリガーはアクションの確定です。
- アクション後も値を保持するには、アクション内で権威あるソースに書き込んでください。オーバーレイ自体は持続しません。
