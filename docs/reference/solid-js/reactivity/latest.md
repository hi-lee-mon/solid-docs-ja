`fn` 内で利用可能な最新の実行中の値を読み取り、現在の確定済みの値にフォールバックします。

## インポート

```ts
import { latest } from "solid-js";
```

## 型シグネチャ

```ts
function latest<T>(fn: () => T): T;
```

## パラメータ

### `fn`

- **型:** `() => T`

読み取る式。コミット済みの値の代わりに実行中の値が返されます。

## 戻り値

コミット済みの値の代わりに実行中の値を読み取ったときに `fn` が返す値。

## 例

```ts
const preview = () => latest(user);
```

## 注意点

- コントロールに使い、コンテンツには使わないでください。`latest` を通じて読み取ったデータは、更新の残りの部分がそれと一致する前に新しい答えを表示する可能性があります。
- 値がまだ存在しない間は、読み取りは通常の読み取りと同様にサスペンドします。
