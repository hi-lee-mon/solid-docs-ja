`fn` 内のリアクティブな読み取りが、まだ公開されていない実行中の値の変更に
依存しているかどうかを返します。

## インポート

```ts
import { isPending } from "solid-js";
```

## 型シグネチャ

```ts
function isPending(fn: () => any): boolean;
```

## パラメータ

### `fn`

- **型:** `() => any`

調べる式。その中で対象の値を読み取ります。

## 戻り値

`fn` 内の読み取りがまだコミットされていない変更に依存している間は `true`。

## 例

### 新しい答えを読み込んでいる間、古い結果を薄く表示する

```tsx
const [query, setQuery] = createSignal("");
const results = createMemo(() => searchProducts(query()));

<ul class={{ stale: isPending(results) }}>
	<For each={results()}>{(product) => <li>{product.name}</li>}</For>
</ul>
```

## 注意点

- 既に存在する値への更新について報告します。最初の値がまだ無い間は、`fn` 内の読み取りは周囲の `Loading` のパスに従います。
- 素の `refresh()` は `isPending` を反転させません。再要求を見えるようにするには `affects()` と組み合わせてください。
